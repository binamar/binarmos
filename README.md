# MP3 Visualizer Studio

Modern, touch-friendly MP3 & audio visualizer web app (built with React, Vite, Tailwind CSS, and Web Audio API) configured to build into an Android APK via Capacitor & GitHub Actions.

## Features
- **7 Reactive Visualization Modes:** Spectrum Bars (with Peak Caps), Wave Ribbon, Radial Halo, Beat Particles & Shockwaves, 3D Horizon Terrain, Harmonic Kaleidoscope, and Spectrogram Waterfall
- **5 Curated Color Palettes:** Amber & Teal, Solaris Heat, Nordic Mint, Crimson Vinyl, and Studio Mono
- **Real-Time Tuning:** Sensitivity, smoothing, detail density, mirror symmetry, luminous trails, and PNG snapshot capture
- **3-Band Live Equalizer:** Real Web Audio `BiquadFilterNode` Bass (100 Hz), Mid (1 kHz), and Treble (8 kHz) controls + Flat, Bass Boost, Club, and Vocal presets
- **Playlist Queue & Demo Synth:** Multi-file drag-and-drop audio queue, playback speed control, looping, live microphone input, and a built-in procedural synth groove
- **Bilingual & Dual-Theme:** Instant English (LTR) / Arabic (RTL) toggle and Light / Dark mode
